# GlowGuide AI 

AI-powered skincare and healthy food assistant built using FastAPI, Streamlit, and Hugging Face Qwen.

## Features
- Personalized skincare recommendations
- Healthy food suggestions
- Interactive AI chatbot
- User profile analysis
- Streamlit frontend
- FastAPI backend
- SQLite chat history storage

## Tech Stack
- Python
- FastAPI
- Streamlit
- Hugging Face Transformers
- Qwen2.5
- SQLite

## Project Structure

```bash
backend/
frontend/
requirements.txt
```

## Run Backend

```bash
uvicorn backend.main:app --reload --port 8002
```

## Run Frontend

```bash
streamlit run frontend/app.py
```
